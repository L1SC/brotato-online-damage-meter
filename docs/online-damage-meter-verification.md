# OnlineDamageMeter 验证记录

日期：2026-09-17。

## 环境与根因

- Brotato 1.1.15.4；内置 ModLoader 6.2.0；Godot 3.7.dev.custom_build.74e86be54。
- 本机已订阅 Brotato Online 6.6.6（工坊 3741034628）和 DmgMeter 2.2.0（工坊 3358859974）。
- Online 在客户端清空波次计时标签的 `wave_timer` 引用，以避免原版更新覆盖房主同步时间；DmgMeter 在引用为空时跳过伤害 HUD 刷新。
- 补丁只在客户端读取当前 Main 的实际波次计时器，刷新前置的原 HUD；不重绑标签引用、不改任何伤害、网络、玩家槽位或存档逻辑。

## 隔离和复现

```powershell
python tools/build_damage_meter.py
python tools/run_damage_meter_tests.py --game-dir 'D:/Program Files (x86)/Steam/steamapps/common/Brotato'
```

基础测试覆盖无补丁基线、仅客户端、双方安装、仅房主和四人安装组合；`--lifecycle` 是额外的结束波次/重试实验流程，可能受 Online 测试场景的重试 UI 时序影响，不作为基础发布判定。

测试只使用本机拥有的游戏 PCK 和已订阅前置 ZIP。私有游戏包与测试运行文件位于 `.local/damage-meter-tests/`，测试项目及存档名称使用 `BrotatoDamageMeterTests-*`；禁用测试项目 Steam 特性及 Online 的 Steam transport，只连接本机 LAN。

安装包和源码包不包含游戏资源、前置 mod、测试运行文件、真实用户存档或 `.codex` 工作记录。

## 范围限制

- 修复客户端本地原 DmgMeter 的显示，不保证两端混合模拟的统计完全相等。
- DmgMeter 三/四人本来只显示前六项；本补丁不改变该规则。
- 尚未实测跨电脑 Steam P2P、互联网延迟、完整 20 波、所有角色/DLC/第三方内容组合。
- DmgMeter 自己声明兼容游戏 1.1.14.1；本补丁声明的目标是实际核查的 1.1.15.4 环境，不替前置承诺全部玩法兼容。
- 本次自动化实际验证的是武器伤害入口及原 HUD 数值刷新；道具/角色来源沿用 DmgMeter 的原统计逻辑，未单独制造每一种来源的测试伤害。
- 基础矩阵覆盖首波真实伤害；一次额外生命周期实验还到达下一波并验证了客户端统计重置，但其重试 UI harness 超时，因此结束波次隐藏、同场景计时器重启和重试路径未作为发布通过条件。
